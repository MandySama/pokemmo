# 中段通行与门禁补充

本章是在用户明确允许“参考端没有时，按现有机制补充”的范围内新增。中文对白为本地补充文案，不是官方文本翻译。

- 砍树：根据现有地图 `EventScript_CutTree` 生成 49 个入口。没有蓝色徽章或秘传机 15 时说明前置；具备二者后询问是／否。确认后短暂停顿、移除本地图树实体，重新入图或重连后恢复。不要求额外教授队伍招式，采用与当前自动冲浪相近的简化野外使用规则。未实现完整原版砍树特效。
- 茶：玉虹大厦一楼 NPC #3 首次交谈获得茶 369；有茶或已有旧领取标记时只衔接对白，不重复发奖。向金黄市任一入口警卫交茶，消耗一杯并永久开放四个入口。没有茶时在原生坐标事件处退回；拒绝交茶保持封锁，普通原地交谈不会强制移动。
- 西尔佛：20 道电子门使用原生地图背景事件、原生关闭图块及碰撞。没有卡片钥匙 355 时说明五楼线索；有钥匙后确认开门，不消耗钥匙。每道门单独保存事件标记，重连保持打开；取消不改变门或其他地图。
- 存档：新事件标记与已有道具奖励／扣除通过同一节点事务保存，幂等防重。树的清除不写永久存档。门图块是角色个人投影，退出世界恢复 ROM 基础图块，不污染其他角色。

## 数据依据

- 本仓库地图资源来自对应参考服务端，NPC、坐标脚本、背景事件和道具编号均逐项核对。卡片钥匙来源为 `world/kanto-items.json` 的 `SilphCo_5F` NPC #7，物品 355。
- 西尔佛门关闭图块来自 pret/pokefirered `data/scripts/silphco_doors.inc` 与 `include/constants/metatile_labels.h`。资源 `provenance` 保存来源 URL 和脚本 SHA-256，开门恢复该地图原始图块，不随意选择邻近地板。
- 金黄警卫事件核对 pret/pokefirered `data/maps/Route5_SouthEntrance/scripts.inc` 的茶与四入口共享状态机制；省略原版警卫走位演出，保留现有对话和通行流程。

- 幽灵塔六楼：无检视镜 359 时退回；有检视镜进入 30 级嘎啦嘎啦野生剧情战，该幽灵不可捕获。胜利后存档并放行，七楼富士老人增加此事件前置。失败／逃跑不推进。
- 12／16 号道路：无宝可梦笛 350 时说明富士老人线索；有笛后可确认唤醒 30 级卡比兽。击败或捕获后按原生 hideFlag 移除对应道路的卡比兽。两处事件独立，失败／逃跑可以重试。
- 卡比兽捕获复用当前模拟捕获事务和投球表现，允许在这类剧情野生战中提交。成功会关闭战斗并续接剧情；失败消耗球但暂不追加敌方回合。并非新增完整捕获率或道具回合系统。普通非剧情 Showdown 野生战的既有限制未扩展。
