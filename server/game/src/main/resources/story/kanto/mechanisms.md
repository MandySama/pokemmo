# 电梯、推石与地图机关

本章沿用现有有限动作执行器，由用户授权补充参考端缺失的执行逻辑。中文说明为本地适配文案。数据生成器为 `tools/story/generate_mechanisms.py`。

- 电梯：玉虹百货 1–5F、西尔佛 1–11F、火箭队本部 B1F/B2F/B4F。入口、面板、楼层与出口来自地图资源及原生 `setdynamicwarp` 脚本。选择楼层后在轿厢等待，走到出口再离开；取消保持原楼层。选定楼层随角色保存，重连可退出。火箭队电梯检查钥匙 356。
- 怪力：持有秘传机 342 且获得彩虹徽章后确认启用，沿用上一轮自动野外技能的简化规则，不额外要求队伍教授招式。向巨石行走会触发推石；墙、其他 NPC、越界、普通传送格和不兼容高度阻止推动。巨石先移动，完成后玩家才进入原格。
- 胜利之路：三层四个压板与挡路岩壁使用原生坐标和图块。巨石压住开关后记录进度和石位，重连保持；未完成的临时推动离图重置。三楼指定洞口可将巨石落到二楼。
- 枯叶道馆：两个随机相邻垃圾桶开关；找错第二个重置，两者均找到后永久关闭电流。首个开关与随机组合在重新入馆时重置；已取得橙色徽章的存档不重新封路。
- 宝可梦屋：各层雕像确认切换同一个共享开关，四层的原生门与雕像图块同步变化，重连保存，可反复切换而非一次性奖励。
- 红莲道馆：六题采用原生的是／否答案。答对开对应门；答错挑战原地图绑定的训练家，只有胜利后开门，败北可重试。直接击败对应训练家也可开门；火山徽章存档保持全部门开启。战后开门通过现有续接节点保存。题目为中文适配，训练家走近的专用动作未复刻。
- 箭头／流水：使用参考 `KantoMetaTileBehaviorType` 的强制方向，旋转地板保持方向直到停止格，仍遵守碰撞。画面使用现有逐格移动，不另造原版旋转特效。
- 双子岛：巨石可按原生洞口逐层落下，目标层石位及落下记录保存。两块均落到 B3F／B4F 时记录对应阻流事件，分别应用原生替代布局的 92／176 个变化格（含碰撞与高度），重连保持。玩家随水流落层的原版专用演出尚未复刻。

## 依据与状态

参考客户端 `ScriptChoiceMenuManager`、`MessageBoxBubble` 多选菜单、`ElevatorWarpTileBehavior`；参考服务端地图及地形行为枚举。原生机关对照 `pret/pokefirered` 的各地图 `scripts.inc`、`data/scripts/pokemon_mansion.inc`、`src/field_specials.c` 和图块常量。`provenance.sha256` 记录明确输入清单的散列；生成器可自动下载缺少的原生输入到忽略缓存，复跑不依赖其他本地整理文件。原生补充源：https://github.com/pret/pokefirered 。

角色机关值保存在 `character_map_mechanism`，已完成／跨层石位保存在 `character_map_boulder`；永久开关沿用 `character_story_event`。图块和实体是个人投影，退出世界恢复基础地图，不修改 ROM。

尚未声称原版完整一周目所有特效、所有可选洞穴和所有机关都已经逐格验收。

验证：`MechanismsTest` 7 项与 `MechanismsUiTest` 的 PC／移动布局 2 项通过；截图和复现命令见 `docs/reference/kanto-mainline.md`。

## 连续实走修正：战斗与推石状态

胜利之路推石途中触发训练家战，结束后只清理战斗／对白会话，不清理当前地图的临时石位、怪力启用状态。仍由真实跨地图的 MAP_READY 重置未完成临时推动；压板和落洞石位继续按既有事务持久化。依据参考服务端 BattleFinishSuccessPacket 只结束战斗管理器，以及既有原生地图机关的离图重置边界。未新增剧情节点或改变 JSON 条件／奖励。

回归检查结束回复重复调用、同地图恢复、继续推动无需重复启用怪力，以及离图返回后石位与怪力正常重置；实际连续存档继续验证三楼推石途中战斗。

## 四天王房间入口与胜后开门

mechanisms.json 同步增加 leagueRooms 和 leagueEntry／leagueExit 图块组，数据由生成器从原生 pokemon_league.inc 及四个房间脚本提取。科拿、希巴、菊子从 (6,12) 自动向上走五格后关闭后门；渡从 (23,13) 按原生走廊顺序走至 (6,10) 后关闭入口。入口原生开放图像带碰撞，只在入场行走动作期间移除对应碰撞，动作 ACK 后恢复原生关闭图块，不开放全局穿墙。

前进门仅在对应实际精英阶段已胜利（elite > 房间 stage）后使用原生开门图块；战败归零后恢复关闭，冠军存档保持开放。SET_ELITE_STAGE 后同时清理实体投影缓存，避免数据库已推进但界面门仍关闭。临时入场状态不作为永久奖励写入。

依据：https://github.com/pret/pokefirered/blob/master/data/scripts/pokemon_league.inc 及各 PokemonLeague 房间 scripts.inc。完整原生门声音／灯光特效仍未复刻。

入场门格断线恢复：leagueRooms.resume 记录原生入口通道范围和剩余终点。重连停在门格时只继续走至室内终点再关闭入口；渡的通道还允许正常走到门前时触发余段，不要求玩家重新传送或穿墙。

最终验证（2026-10-27）：league-final-regression 共 36 项通过（含 PC／移动布局及成长依赖），continuation-lapras-route 连续副本实际战胜冠军并进入名人堂，BUILD SUCCESSFUL；八徽章与 champion=1 已核验落档。保留原档和永久备份未修改，完整片尾演出仍未复刻。
