# kanto.postgame

用途：补齐冠军后的七岛前置、红蓝宝石任务、华蓝洞窟入口与强化联盟再挑战。通过现有有限剧情运行器实现；不读取或覆盖 GBA `.sav` 文件，不把额外捕获或任务标记补进玩家存档。

## 来源与适配

- 参考服务端 `Pokemmo2Pro-Server/resource/story/kanto` 未提供二周目章节；复用其 `StoryActionExecutor` 的对话、移动、切图、训练家战、事务和续接方式，以及现有训练家目录的原生队伍。
- 参考客户端既有对话泡、是／否、多选列表、战斗窗口和统一名人堂。不增加世界按钮，PC 和移动端共用交互入口。
- 按用户授权，以 [FireRed 原生地图脚本](https://github.com/pret/pokefirered/tree/master/data/maps) 补充缺失数据。全国图鉴条件、通行证、宝石、盲文方向、密码、队伍和机关格来自对应脚本、`include/constants/items.h` 和 `metatile_labels.h`，不是根据截图猜数值。作者调查快照与 SHA256 位于本地 `docs/reference/native-postgame/sources.json`。
- `generate-postgame.py` 可重生成 JSON。中文对白为本地简述，非官方译文。省略原版的逐步演员走位、偷宝石研究员落下动画、完整乘船过场；切图复用已有动作。渡船将原版分页面目的地合并到现有可滚动选项列表，仍保留通行证限制与取消。
- 全国图鉴采用 GBA 的一之岛访问及至少 60 种关都“拥有”记录条件，以本地旗标表示剧情升级；当前图鉴本来已支持全国数据，不另外制作一种图鉴窗口。此门槛是 GBA 适配，未宣称已核实当前官方 PokeMMO 的相同门槛。

## 剧情分支与状态

1. **旧冠军补七岛前置**：红莲岛首次进入或与正辉交谈 → 是／否登岛；拒绝不出发。进入一之岛中心介绍锦辉，事务发陨石 280 和三岛通行证 367，一次领取。二之岛父亲求助 → 三之岛四连战（527／528／529／742）→ 树果森林 30 级引梦貘人 → 救回洛丝丽并获得异奇果 147 → 二之岛交陨石，获得月之石 94 → 回一之岛正辉处完成旅行前置、返回红莲。未完成的冠军旧档可以补做，不要求重打一周目。
2. **全国图鉴**：冠军与研究所博士交谈；先访问一之岛，拥有至少 60 种关都宝可梦后保存 `FLAG_SYS_NATIONAL_DEX`。不足则说明条件；重谈不重复发奖励。
3. **红宝石**：锦辉请求 → 灯火山两队员（537／538，可任意顺序）→ 保存第一段密码与各自胜利标记，两人都败后消失 → B5F 红宝石 373 → 锦辉收走红宝石与三岛通行证，发七岛通行证 368。灯火山入口地块随请求打开，红宝石不会在未击败守卫时领取。
4. **四至七岛**：七岛通行证开放全部岛港；三岛通行证只开放前三岛与枯叶。当前岛不列为目的地，末项取消，无道具消耗。各岛港可以往返。
5. **蓝宝石**：冰瀑洞窟协助科拿战胜火箭队（539）→ 火箭队／科拿离场，遗迹山谷研究员让路 → 按现有自动秘传技机制，以居合斩（兼容旧任务道具 15 与目录 HM 339）打开点之穴 → 原 ROM 洞口传送和上／左／右／下盲文 → 蓝宝石被科学家偷走，保存第二段密码，**此时不给背包蓝宝石** → 五之岛仓库检查两段密码开门 → 干部 543／544 和科学家 545 → 战胜科学家才获得蓝宝石 374。干部视线开战也续接同一任务，不能掉回普通训练家战而漏发宝石。
6. **交付完成**：锦辉收蓝宝石后保存 `FLAG_SYS_CAN_LINK_WITH_RS`，网络机器地块显示宝石及亮屏，华蓝洞窟守卫消失、科拿可归队。重复交谈不再收物品。华蓝洞窟超梦为 70 级可捕获脚本遭遇，胜利／捕获后隐藏，失败回华蓝中心。
7. **强化联盟**：网络机器完成后，进入科拿房间建立新挑战，独立清零四天王阶段；使用 735～738 强化队伍，冠军按玩家初始精灵分支使用 741／740／739。逐战打开出口，战败清零本次挑战、治疗并回联盟中心；回联盟中心离开挑战也清零。冠军标记保留，不重放一周目一次性奖励。
8. **再次名人堂**：强化冠军胜后清本轮阶段，重建本次名人堂队伍快照，播放现有演出后回联盟外。可以再次从科拿挑战。战斗金钱／经验由已有战斗结算处理，剧情不额外加一次奖金。

## 持久化与边界

事件旗标沿用 `character_story_event`，道具发放／交付／旗标在既有节点事务内幂等提交。断线后的战斗胜利续接使用 `character_story_resume`；不靠客户端单独保存宝石。强化联盟是否在挑战使用 `character_map_mechanism` 的 `postgame/league_active`，不更改已有主线表结构。现有“地图剧情”窗口显示二周目下一步及渡船选项分支。

本次范围是二周目核心主链；没有实现原版漫游三圣兽、七岛全部支线小游戏、诞生岛／脐之岩活动船票、完整 GBA 动画或新的存档导入器。冲浪沿用当前项目已授权的自动机制。冰瀑地形逐格机关没有作为本次新增内容，不能将检查点测试称为全地图自然步行通关。

验证方式与结果见 `docs/testing/kanto-postgame.md`，区分原样存档条件、受控图鉴／队伍测试前置与真实 UI 战斗。

战斗断线恢复：核心链的真实战斗支持同存档 5 分钟重连，保留回合与剧情战胜负续接，超时按放弃走既有战败处理，不额外发剧情奖励。此修改属于运行时恢复，不改变本 JSON 的任务分支；实现与验证见 `docs/reference/battle-reconnect.md`。
