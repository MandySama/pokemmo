# 真新镇读牌女孩

对应 `sign-lady.json`。依据参考服务端 PalletTown 地图、参考客户端 NPC 自动移动，以及源地图脚本 `pret/pokefirered/data/maps/PalletTown/scripts.inc`。

| 状态 | 触发条件 | 行为与结果 |
| --- | --- | --- |
| 0，未读牌 | 女孩旁交谈 | 对话、惊叹号、让开一格；本次地图中提醒读牌 |
| 0，入口教学 | 已领初始宝可梦后进镇 | 女孩位于 (12,2)，交谈或经过 (13,2) 触发教学 |
| 1，刚读牌 | 看提示牌或完成教学 | 再交谈说明提示牌有用；本次地图保留剧情位置和固定朝向 |
| 2，教学完成 | 状态 1 后重新进入真新镇 | 恢复参考地图出生点 (3,10)、随机走动，横向范围 1、纵向范围 4；交谈显示养育宝可梦对白 |

阶段变量：`character_kanto_variables.variable=16496`（0x4070）。`character_pallet_sign_lady` 保存教学过程的位置，不应覆盖阶段 2 的原地图移动定义。客户端自动走动不逐格写入存档。

## 验收与排查

1. 用地图剧情的“修改条件／重复测试”分别验证状态 0、1、2。状态修改后重新进地图，验证地图进入逻辑。
2. 对照“当前分支”验证触发条件、对白、位置、朝向、移动方式、范围、可见性，以及结束后是否解除交谈／脚本锁。分支匹配只证明条件成立。
3. 等待至少 15 秒观察自由活动；再次交谈，确认停下并面对玩家；结束后继续观察是否恢复活动。
4. 离开重进和退出重登都要验证，防止只在当前会话正确。
5. 状态不对查服务端变量和动作提交；位置／移动定义不对查服务端实体投影；定义正确但不动查客户端 `WorldNpcMotion` 的 `talking`、`scripted` 和碰撞检查；每次请求后回原点查快照是否反复重建演员。

回归用例：`PalletSignLadyTest` 验证分支、重登和移动定义；`PalletSignLadyUiTest` 在 PC 与移动布局实际运行读牌流程，验证完成后走动、范围及再次对话。
