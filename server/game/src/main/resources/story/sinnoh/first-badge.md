# 神奥首枚徽章

用途：将白金开场至黑金道馆煤炭徽章接入当前 RegionalStory 对话/选项/战斗/换图引擎。参考服务端没有神奥剧情脚本，按用户授权复用现有合众引擎；不新造界面。

来源：本地白金 ROM SHA256 `67de86a1bc8e7eb6479dbbbd6e8f5edfc2fa160576a38e40e06d2180ed63b110`。地图头、NPC位置/graphics来自 ARM9+zone_event.narc；队伍、等级、招式、IV来自trdata/trpoke；对话来自pl_msg.narc原英文文本。客户端加载方式核对指定参考 PlatinumRom、DpptMapZoneEvents、NdsRibbonMedalEntry/NdsRibbonRequirementEntry。剧情顺序/分支另核对 pret/pokeplatinum commit `579d2d5c65e736a1a4268fb7acbfd70712177c6c` 的对应地图脚本。生成入口 `server/game/sinnoh-reference/generate.py`。

## 状态与触发

0卧室TV/劲敌开场 → 1进入201号道路，山梨询问（否可循环）、三选一（草苗龟/小火焰猴/波加曼） → 2原生劲敌首战（胜负均回家恢复） → 3心齐湖赤日剧情 → 4真砂研究所，接受图鉴（否循环） → 5回家取日记/包裹 → 6在202号道路领取5球/捕捉讲解 → 7祝庆帅哥、学校向劲敌交包裹/领地图 → 8三个小丑答题（错不发券，三券齐全才能换表） → 9在203号道路与劲敌战斗 → 10黑金关口领HM06 → 11矿坑与瓢太交谈 → 12道馆挑战 → 13煤炭徽章/TM76。

首战对手由初始选择分支为851/852/850；203对手248/249/247；馆主246原生队伍：小拳石12、大岩蛇12、头盖龙14。首章道路/关口/矿坑/道馆的21名训练家使用原始队伍，普通训练家胜后置唯一标记。馆主获胜同时置两名道馆训练家已胜标记。失败不发徽章，移回中心并恢复。母亲与三个中心护士可恢复HP/异常/PP。

存档独立表character_sinnoh_story；节点/动作下标/位置/初始选择/标记逐步持久化。奖励和进度提交在同一事务，物品有唯一标记；包裹交付从背包移除。过期回复序号拒绝推进。徽章位仅胜利结算后设置。
