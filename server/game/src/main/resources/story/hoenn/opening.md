# 丰缘开局

来源：参考服务端 Hoenn 地图；pret/pokeemerald 原生地图脚本；本机 BPEE rev0 ROM 文本偏移。参考客户端未提供可直接移植的丰缘剧情，按用户授权复用现有剧情动作执行器。

- 阶段 0～5：卡车搬家 → 妈妈迎接 → 新家 → 调查楼上时钟 → 下楼看电视。男女角色使用各自房屋。
- 阶段 6～8：拜访隔壁 → 上楼认识劲敌 → 101 号道路救博士。未认识劲敌前，镇北出口提示需要宝可梦。
- 首次进入劲敌卧室时劲敌隐藏，调查房间里的精灵球后按原生 `addobject` 分支出场；见面后重进卧室回到电脑旁，不再预先显示在不可接近的原始出生格。
- 劲敌靠近与返回电脑的路线按原生四个调查方向分别导入，避免固定终点与玩家重叠。选完初始精灵后按原生 `setobjectxy` 直接设置救援战斗站位，不能用忽略交互目标的普通寻路穿过精灵球阻挡。
- 地图剧情查看按玩家当前朝向标记上述分支，只预览，不执行出场或写入事件标记。
- 阶段 9～12：背包三选一（木守宫／火稚鸡／水跃鱼）→ 三级蛇纹熊 → 博士研究所 → 103 号道路劲敌。
- 阶段 13～16：胜后返回研究所 → 图鉴和五个精灵球 → 妈妈赠送跑步鞋。劲敌战败则治疗并返回家中，可重试。
- 初始精灵、精灵球只发放一次；丰缘进度与关都独立，战斗后节点可恢复。已有角色不自动重置或补建剧情。

适配限制：时钟使用现有确认框记录时间，未实现 GBA 指针钟界面；初始选择复用选项框；未接入昵称询问；卡车演出复用等待与地图切换。劲敌队伍和服务端训练家元数据使用原生设置，但对战出场立绘仍受现有通用 NPC 表现限制，尚未专门接入绿宝石劲敌立绘。阶段 16 起由同目录 `mainline.json` 接续；自然路线机关和完整原生演出限制见 `mainline.md`。

验证：独立临时数据库覆盖男女角色、三种初始选择、两场剧情战斗后的节点恢复、奖励去重。该测试通过检查点推进并模拟战斗结果，不等同于完整自然行走或实战通关。客户端另有桌面／移动布局真实渲染开场测试。
