额外交互：普通直接声明训练家战斗、无分支固定对话、精灵中心护士、居合斩／碎岩／怪力秘传机、哈奇渡船、缆车。秘传机使用现有道具界面教学；野外居合斩、碎岩、怪力、潜水按徽章＋秘传机＋队伍招式检查。碎岩／砍树复用临时移除，怪力复用逐格推动；没有擅自把所有隐藏 NPC 显示出来。
