# PokeMMO

基于 Java 复刻 PokeMMO，目前已接通桌面客户端、登录服务和游戏服务的入服流程。

## 项目结构

| 目录 | 说明 |
| --- | --- |
| `client` | 桌面窗口、渲染、登录界面、音频播放与网络认证 |
| `twl-core` | TWL 核心源码模块，通过 Maven 模块依赖提供给客户端 |
| `data` | 外部资源，包括窗口图标、主题、字体、背景图片和语言 XML |
| `roms` | 导入的 ROM 文件，在首次导入时创建 |
| `config` | 客户端本地配置，在首次导入时创建 |
| `protocol` | 客户端、登录服务与游戏服务共用的封包、握手、加密通道及入服凭证 |
| `sever/login` | TCP 登录服务、数据库账号认证与凭据签发 |
| `sever/persistence` | PostgreSQL 连接、业务表初始化、账号与角色存储及管理工具 |
| `sever/game` | 游戏服务监听、入服验证、在线会话和心跳 |
| `sever/chat` | 聊天服务模块 |

`sever` 为当前项目使用的目录及模块名称。

## 开发与运行

环境要求：JDK 21、Maven，以及支持 OpenGL 的 Windows 桌面环境。当前 LWJGL 原生依赖按 Windows 配置。

在项目根目录编译：

```shell
mvn compile
```

在 IntelliJ IDEA 中打开根目录的 `pom.xml` 并加载 Maven 项目，使用 `client` 模块的类路径运行：

```text
top.totodile.pokemmo.Main
```

运行配置的工作目录设为项目根目录；也支持从 `client` 目录运行。外部 `data` 目录需保留，资源不会自动打入客户端 JAR。

可通过运行配置的 VM options 指定登录服务器：

```text
-Dpokemmo.login.host=127.0.0.1 -Dpokemmo.login.port=2106
```

Java 和 XML 尽量采用 IntelliJ IDEA 默认格式。控件尺寸、焦点规则、通知时序等实现细节在对应代码与主题注释中维护。

先在客户端管理中导入火红 ROM。给客户端入口添加以下 VM options，可打开独立地图测试界面，从真新镇开始，无需启动登录和游戏服务：

```text
-Dpokemmo.test.map=kanto -Dpokemmo.preview.enhanced=true
```

对比原始绘制：

```text
-Dpokemmo.test.map=kanto -Dpokemmo.preview.enhanced=false
```

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖拽 | 平移镜头，室外相邻地图按连接拼接 |
| 鼠标滚轮 | 以指针位置缩放，1–4 倍整数倍率 |
| 点击青色传送点框 | 进入房间、洞穴或切换楼层；也可关闭标记后点击同一格 |

| “返回”或 Backspace | 回到上一次传送前的地图和镜头位置 |
| “真新镇”或 Home | 返回真新镇并清空传送历史 |
| “增强绘制” | 保持当前位置切换原始与增强绘制 |
| “传送点标记” | 显示或隐藏传送事件格的边框 |

测试界面支持下方的季节和时间参数，切换增强模式时保持相同环境。真新镇的室外连接网络在当前卡带中包含 37 张地图；室内、洞穴及其他区域可通过传送点或地图列表访问。

单张地图静态预览仍使用以下 VM option，默认打开关都出生房间：

```text
-Dpokemmo.preview.map=kanto
```

预览读取本地 ROM 配置，不需要连接服务器；移除此参数后恢复登录界面和登录服务。

可通过以下参数指定地图和预览环境；默认地图组为 `4`、地图编号为 `1`，季节为夏季，时间为中午 12:00。季节编号 `0/1/2/3` 分别对应春、夏、秋、冬。

| VM option | 说明 |
| --- | --- |
| `-Dpokemmo.preview.group=3` | 地图组编号；组 `3` 包含室外城镇和道路 |
| `-Dpokemmo.preview.id=0` | 组内地图编号；`3/0` 为真新镇，`3/3` 为华蓝市 |
| `-Dpokemmo.preview.season=3` | 季节编号 |
| `-Dpokemmo.preview.hour=0` | 小时，范围 `0～23` |
| `-Dpokemmo.preview.minute=0` | 分钟，范围 `0～59` |
| `-Dpokemmo.preview.enhanced=false` | 关闭增强，显示原始 ROM 静态地图；默认 `true`。对比时保持其他参数相同，窗口标题会标明当前模式 |

例如查看真新镇的冬季夜景：

```text
-Dpokemmo.preview.map=kanto -Dpokemmo.preview.group=3 -Dpokemmo.preview.id=0 -Dpokemmo.preview.season=3 -Dpokemmo.preview.hour=0
```

先使用 `sever/game` 模块的类路径启动游戏服务：

```text
top.totodile.pokemmo.game.Main
```

再使用 `sever/login` 模块的类路径运行登录服务入口，最后启动客户端：

```text
top.totodile.pokemmo.login.Main
```

启动服务前准备 PostgreSQL：将 `sever/persistence/database.example.properties` 复制到 `config/database.properties`，填写新的数据库名称、用户名和密码。该文件已忽略 Git。两个服务的工作目录均设为项目根目录；其他工作目录可用 `-Dpokemmo.database.config=绝对路径` 指定配置，游戏服务同时用 `-Dpokemmo.avatar.pack=绝对路径` 指定 `addons.pak`。`POKEMMO_DB_URL`、`POKEMMO_DB_USER`、`POKEMMO_DB_PASSWORD` 可覆盖文件对应值。

首次使用 `sever/persistence` 模块类路径运行 `top.totodile.pokemmo.persistence.DatabaseAdmin`。工具使用 PostgreSQL 维护库执行建库，按 `template0` 创建独立数据库并初始化表；同名库已存在时拒绝复用。服务启动在事务锁中检查并创建缺失的业务表，现有数据保留；连接或建表失败时停止启动，不回退到内存存储。JDBC 驱动使用 [pgJDBC](https://jdbc.postgresql.org/download/)。

登录服务首次启动时创建缺失的默认账号 `MandySa`，密码见服务启动配置；环境变量 `POKEMMO_LOGIN_USERNAME` 和 `POKEMMO_LOGIN_PASSWORD` 可覆盖初始值。已有账号不会被重新初始化或覆盖密码，账号 ID 保持稳定。认证通过后进入服务器选择窗口。

创建其他账号可使用 `sever/persistence` 模块类路径运行 `top.totodile.pokemmo.persistence.AccountAdmin 用户名`，通过控制台隐藏输入密码；IDE 无交互控制台时设置 `POKEMMO_ACCOUNT_PASSWORD` 环境变量。工具遇到同名账号时保持原账号不变。

服务端 VM options：

```text
-Dpokemmo.login.bind=127.0.0.1 -Dpokemmo.login.port=2106
```

项目内置一对本地开发用 P-256 握手密钥，私钥仅随登录与游戏服务模块提供，公钥由协议模块提供。支持用服务端 `-Dpokemmo.login.privateKey=路径` 和客户端 `-Dpokemmo.login.publicKey=路径` 替换为匹配的 DER 文件（私钥 PKCS#8，公钥 X.509）。认证请求使用 UTF-16LE 字符串和 SHA-1 密码摘要，封包使用小端长度头；每次连接独立协商加密密钥，双向分别维护加密流；登录使用带序号的 HMAC，游戏使用密文 CRC16。登录认证后保留连接，用于请求服务器列表及入服凭证；游戏入服成功后客户端释放登录连接。

游戏服务默认监听 `127.0.0.1:7777`，节点 ID 为 `1`，容量为 `100`。运行配置支持：

| 运行配置 | VM options |
| --- | --- |
| 游戏服务 | `-Dpokemmo.game.bind=127.0.0.1 -Dpokemmo.game.port=7777 -Dpokemmo.game.id=1 -Dpokemmo.game.capacity=100` |
| 登录服务中的游戏节点 | `-Dpokemmo.game.host=127.0.0.1 -Dpokemmo.game.port=7777 -Dpokemmo.game.id=1 -Dpokemmo.game.name=Live` |

两处节点 ID 和端口需匹配。游戏服务未启动时，列表显示“关闭”；启动后列表自动刷新。选择服务器后，游戏服务验证一分钟有效的签名凭证，认证通过则进入角色选择窗口；“注销”返回登录页并释放游戏会话。入服凭证消费记录、在线账号和负载只保存在服务进程内存中。

游戏服务私钥可用 `-Dpokemmo.game.privateKey=路径` 替换。两个服务默认共用开发密钥；更换时需保持签名与信任公钥匹配，并在客户端及两个服务配置 `-Dpokemmo.login.publicKey=路径`。游戏心跳使用 `0x20`，每十五秒发送一次；节点探测使用 `0x7E` 扩展封包，经游戏加密通道返回在线人数与容量。

### 世界通行数据

游戏服务从协议资源 `maps/fire-red-world.gz` 读取全部 425 张地图的阻挡、高度、地块行为、静态 NPC 占位、连接与传送数据，不需要加载图像或 OpenGL。修改卡带通行数据后，可通过客户端模块类路径运行 `top.totodile.pokemmo.tools.ExportWorldRules <火红ROM路径> <输出.gz路径>` 重新导出，然后重新构建协议及服务模块。

游戏服务参数 `-Dpokemmo.game.debug=false` 可关闭倍速、穿墙和调试传送，当前默认开启以支持开发菜单。客户端和 game 服务需要使用同一版本；本次游戏校验及移动协议变更后应同时重启，登录服务更新连接池后也应重启。
