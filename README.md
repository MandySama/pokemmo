# PokeMMO

基于 Java 复刻 PokeMMO，目前主要开发桌面客户端的登录界面。

## 项目结构

| 目录 | 说明 |
| --- | --- |
| `client` | 桌面窗口、渲染、登录界面与初始网络连接 |
| `twl-core` | TWL 核心源码模块，通过 Maven 模块依赖提供给客户端 |
| `data` | 外部资源，包括窗口图标、主题、字体、背景图片和语言 XML |
| `sever/login` | 登录服务模块 |
| `sever/game` | 游戏服务模块 |
| `sever/chat` | 聊天服务模块 |

`sever` 为当前项目使用的目录及模块名称。

## 当前实现

| 功能 | 已实现内容 |
| --- | --- |
| 桌面窗口 | 窗口图标、主屏工作区居中及窗口缩放适配 |
| UI 与渲染 | TWL 控件、XML 主题、GLFW/OpenGL 渲染及 FreeType 字体绘制 |
| 界面文本 | 自动发现语言 XML，按字符串 ID 读取文本，支持切换与主语言回退；当前提供简体中文 |
| 登录画面 | Logo、循环滚动的图片背景、左上角 ROM 信息占位及右下角按钮区 |
| 登录表单 | 用户名、密码、记住我和登录按钮，以及输入、焦点切换、选区、剪贴板及右键菜单交互 |
| 登录状态与通知 | “登录中...”状态、失败后的表单恢复，以及可堆叠、自动消失的通知 |
| 客户端管理窗口 UI | 语言下拉列表、各版本 ROM 的选择与信息按钮、打开 ROM 文件夹按钮和关闭操作 |
| MOD 管理窗口 UI | 空列表提示、获取与导入 MOD、打开 MOD 文件夹、调试详情复选框、保存按钮和关闭操作 |
| 设置窗口 UI | 影像、声音、界面、游戏、控制、语言、聊天、工具和联动分类，以及下拉、勾选、数值调整、滚动和关闭交互 |
| 初始网络连接 | 异步 TCP 连接、初始握手、重试及通信失败提示，默认地址为 `127.0.0.1:2106` |

## 开发与运行

环境要求：JDK 21、Maven，以及支持 OpenGL 的 Windows 桌面环境。当前 LWJGL 原生依赖按 Windows 配置。

在项目根目录编译：

```shell
mvn compile
```

在 IntelliJ IDEA 中打开根目录的 `pom.xml` 并加载 Maven 项目，使用 `client` 模块的类路径运行：

```text
top.totodile.pokemmo.Main
```

运行配置的工作目录设为项目根目录；也支持从 `client` 目录运行。外部 `data` 目录需保留，资源不会自动打入客户端 JAR。

可通过运行配置的 VM options 指定登录服务器：

```text
-Dpokemmo.login.host=127.0.0.1 -Dpokemmo.login.port=2106
```

Java 和 XML 尽量采用 IntelliJ IDEA 默认格式。控件尺寸、焦点规则、通知时序等实现细节在对应代码与主题注释中维护。
